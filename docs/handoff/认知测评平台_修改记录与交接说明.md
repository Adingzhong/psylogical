# 认知测评平台修改记录与交接说明

## 1. 文档目的

这份文档用于后续协作者理解当前认知测评平台的真实实现状态，重点说明当前版本与原始设计、开发文档、试测反馈和已有证据之间的差别。它不是新开发计划，也不是单纯的 commit 汇总。

本次整理只关注当前仓库内的认知测评平台，主要目标是让刘晓烨、许一桦、黄朝琮、戴敬力等同学根据自己原来负责的范式，快速确认当前修改是否合理、是否会影响实验效度或数据质量。

说明：`CLAUDE.md` 已阅读，但仅作为可能过期的项目概览参考；本文件的结论优先来自当前代码、代码注释、原始开发文档、反馈/证据文件和 git commit 交叉核对。

## 3. 总体发现

当前可交接的 Web 认知测评平台主要位于 `web-battery/`。重点范式代码集中在 `web-battery/paradigms/`，共享触控、进度、保存、完成页、录音/录像等公共能力在 `web-battery/lib/` 和 `web-battery/server/`。

原始开发文档主要位于 `开发文档/`、各旧版 PsychoPy 范式目录和少量 `.docx/.pptx/.xlsx` 文件中。试测反馈和修改依据主要位于 `4月6日 反馈/`、`4月18日 修改/`、`UX图片/`、`按钮修正/`。

需要人工确认的重点集中在这些地方：

- 空间导航：当前代码练习最大轮数为 2 轮，但文档/文件头有 3 轮说法。
- RMET：当前为 1 练习 + 10 正式的简化短版，需要确认题量和难度是否符合研究目标。
- N-back/图片记忆：`CLAUDE.md` 写 B4 removed，但当前代码仍保留 B4 条件门控；B3 cue 时长也与 `N-back视老化改造_文献依据.md` 的最终建议不一致。
- TMT：当前代码取消正式任务 40 秒硬上限，改成 `Infinity`，与原始 TMT 文档差异较大。
- 画钟：当前 Web 版本包含命令作图和临摹条件，并保存轨迹/撤销/截图；需要确认是否只纳入画钟，还是也保留临摹。
- 语音：当前是每题自动开始、点击下一题时停止的单题录音，尚未实现主持人手动开始/停止录音。

另外，仓库中存在不少不建议直接上传 GitHub 的内容：`web-battery/server/data/` 下的测试/被试数据和音频、`web-battery-https-certs/lan.key`、`4月19日 修改/hospital_query/data/queue.db`、`.pptx` 临时文件、备份音频目录、`node_modules`、`.pw-browsers`、测试下载与运行日志等。
