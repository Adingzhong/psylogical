# 认知测评平台协作者审核说明

## 这份文档给谁看

这份文档给原始范式负责人和后续协作者看。它的目标不是讲代码细节，而是让每个人快速知道：

- 我负责哪个范式；
- 当前 Web 版本和原始设计相比改了什么；
- 原始开发文档、旧版程序、证据文件在哪里；
- 哪些改动需要用心理学和实验范式知识确认是否合理。

如果需要更详细的技术线索，请再看 `docs/handoff/认知测评平台_Codex交接说明.md` 和 `docs/handoff/认知测评平台_修改记录与交接说明.md`。

## 仓库里主要看哪里

| 位置 | 用途 |
|---|---|
| `web-battery/` | 当前 Web 认知测评平台，真正运行的代码在这里 |

| `web-battery/audio/` | 当前 Web 版本使用的指导语音频 |

| `4月18日 修改/` | 反应时、呈现时间、文献原文核实材料 |

审核时不用先找代码行号。请先打开对应文件夹和文件，结合原始设计、反馈证据和当前代码注释判断改动是否合理。

## 建议的人工审核流程

1. 先看自己负责的表格行。
2. 打开“原始文件/开发文档”，确认原先设计逻辑。
3. 打开“当前 Web 实现”，粗看当前版本怎么做。
4. 打开“证据在哪里”，判断这些修改是否有试测反馈或文献依据。
5. 针对“必须审核”列给出结论：接受、需要修改、需要补证据、暂不确定。
6. 如果需要让 Codex 协助，只让它围绕一个范式回答，不要一次性让它重扫全仓库。
