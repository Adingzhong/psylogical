# handoff 交接说明入口

这个目录用于认知测评平台的代码交接和范式审核。

建议阅读顺序：

1. `认知测评平台_协作者审核说明.md`
   - 给刘晓烨、许一桦、黄朝琮、戴敬力等原负责人看的精简版。
   - 重点说明：自己负责什么、当前版本改了什么、证据和原始文件在哪里、哪些地方必须人工确认。

2. `认知测评平台_Codex交接说明.md`
   - 给 Codex / ChatGPT / 其他代码助手看的工作说明。
   - 重点说明：接下来如何协助人工审核、应该看哪些目录、如何做三路对照、输出应该保持简洁。

3. `负责人审核Prompt与CSV检查.md`
   - 给刘晓烨、许一桦、黄朝琮三位原范式负责人使用。
   - 每个人都有两段：一段是直接发给人的话，另一段是负责人复制给 Codex 的机器审核 prompt。
   - 机器 prompt 会引导 Codex 自己读取 handoff、代码、原始文档、证据和 CSV 输出索引。

4. `CSV输出结构审核索引.md`
   - 给负责人和 Codex 快速定位每个范式的数据输出结构。
   - 审核字段是否够后续统计分析时先看这一份。

5. `审核材料充分性检查.md`
   - 说明当前 GitHub 包到底够不够审核、已经补了哪些证据和材料、哪些内容是故意不上传。
   - 如果担心“为什么没有完整大图/录音/旧版 zip”，先看这一份。
   - 机器要快速查材料清单时，可看 `当前上传材料清单.csv`。

6. `GitHub协作版上传说明.md`
   - 说明首次 GitHub 协作版为什么优先上传代码、文档、CSV/JSON 和轻量证据。
   - 大体积原始图片、旧版 zip、眼动素材建议后续分批、Git LFS 或 Release 管理。

7. `认知测评平台_修改记录与交接说明.md`
   - 详细扫描底稿。
   - 内容更长，包含更多 commit、代码注释、参数和风险记录。需要深挖某个范式时再看。

本目录只做交接说明，不代表新开发计划，也不要求直接改代码。
