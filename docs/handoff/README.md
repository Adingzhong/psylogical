# handoff 交接说明入口

这个目录用于认知测评平台的代码交接和范式审核。

建议阅读顺序：

1. `认知测评平台_协作者审核说明.md`
   - 给刘晓烨、许一桦、黄朝琮、戴敬力等原负责人看的精简版。
   - 重点说明：自己负责什么、当前版本改了什么、证据和原始文件在哪里、哪些地方必须人工确认。

2. `认知测评平台_Codex交接说明.md`
   - 给 Codex / ChatGPT / 其他代码助手看的工作说明。
   - 重点说明：接下来如何协助人工审核、应该看哪些目录、如何做三路对照、输出应该保持简洁。

3. `负责人审核Prompt与CSV检查.md`
   - 给刘晓烨、许一桦、黄朝琮三位原范式负责人分别复制使用的 prompt。
   - 重点说明：如何展开科研验证、如何检查 CSV/JSON 输出是否够后续分析。

4. `GitHub协作版上传说明.md`
   - 说明首次 GitHub 协作版为什么优先上传代码、文档、CSV/JSON 和轻量证据。
   - 大体积刺激图片、音频、眼动素材建议后续分批、Git LFS 或 Release 管理。

5. `认知测评平台_修改记录与交接说明.md`
   - 详细扫描底稿。
   - 内容更长，包含更多 commit、代码注释、参数和风险记录。需要深挖某个范式时再看。

本目录只做交接说明，不代表新开发计划，也不要求直接改代码。
