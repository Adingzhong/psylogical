# 审核材料充分性检查

## 结论

当前 GitHub 协作版已经足够支持三位负责人做第一轮科研审核：看参数、看流程、看当前代码、看 CSV/JSON 输出结构、看原始开发文档、看关键文献证据、看当前实际使用的指导语和刺激材料。

它不是完整复现实验的网盘包。没有上传原始大图副本、旧版 zip、数据库、被试数据、日志、缓存、venv、node_modules、眼动多模态大素材，也没有上传所有历史过程图。

如果负责人要做“材料像素级复核”或“重新运行旧版 PsychoPy 程序”，需要再按范式单独补全原始素材包；这不是本轮 GitHub 主仓库的目标。

## 没有上传但有意排除的内容

| 内容 | 原因 |
|---|---|
| 原始 PNG/JPG 大图副本 | 当前代码主要使用 WebP；原始副本体积大，审核阶段不需要 |
| `web-battery/server/data/` | 可能含被试数据、录音、轨迹和截图 |
| `web-battery/server/logs/` | 本地日志 |
| HTTPS 私钥和证书 | 不应公开 |
| `node_modules/`, `.pw-browsers/`, venv | 依赖和浏览器缓存，不属于审核材料 |
| 各类 `.zip` 大包 | 重复、体积大、内容不透明 |
| `眼动多模态/` 大素材 | 不是本轮认知测评平台审核重点 |
| 伦理审查正式材料 | 公开前需要人工确认 |
| RMET result CSV | 原始测试结果，不应公开 |

## 给负责人的阅读顺序

1. 先看 `docs/handoff/README.md`。
2. 再看 `docs/handoff/认知测评平台_协作者审核说明.md`。
3. 复制自己在 `docs/handoff/负责人审核Prompt与CSV检查.md` 里的 prompt。
4. 打开自己负责范式的当前代码、原始文档、证据文件。
5. 输出结论：接受、需要修改、需要补证据、暂不确定。
