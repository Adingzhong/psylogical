# 语音指导语设计规范调研报告

> 调研日期：2026-04-08
> 适用平台：老年MCI认知筛查平台（Surface平板，65+老人，触屏操作）
> 目标：将现有文字指导语改为语音引导，所有参数有文献支撑

## 1. 语速（Speech Rate）

### 1.1 英文基准数据

| 场景 | 语速（wpm） | 来源 |
|------|------------|------|
| 正常对话 | 140–180 wpm | ASHA Leader, 2005 |
| 清晰语音（clear speech，年轻听者） | 约125 wpm | Krause & Panagiotopoulos, 2019 |
| TTS推荐起始速率（失语症患者） | **150 wpm** | Hux et al., 2019（PMC7231913） |
| TTS三档测试：慢档 | **113 wpm**（SD=5.5） | Hux et al., 2019 |
| TTS三档测试：中档 | **154 wpm**（SD=9.5） | Hux et al., 2019 |
| TTS三档测试：快档 | **200 wpm**（SD=10.4） | Hux et al., 2019 |
| 段落理解最佳（有认知困难者） | **120 wpm优于150 wpm** | Hux et al., 2019 |
| 老年人VUI偏好 | 低于自身说话速率 | Wang et al., 2023（Frontiers Psych） |

**关键发现**：Hux等（2019）测试了三档TTS速率，慢档（113 wpm）理解正确率75.1%、中档73.7%、快档71.3%，趋势显著，推荐**150 wpm作为起始值**，对有理解困难者应降至120 wpm以下。Wang等（2023）发现老年人期望系统反馈语速**低于自身说话速率**，且存在个体差异，建议动态适配。

> 文献：
> - Hux, K., Brown, J. A., Wallace, S., et al. (2019). Effect of text-to-speech rate on reading comprehension by adults with aphasia. *American Journal of Speech-Language Pathology*, 29(1), 168–184. https://doi.org/10.1044/2019_AJSLP-19-00047（PMC: [PMC7231913](https://pmc.ncbi.nlm.nih.gov/articles/PMC7231913/)）
> - Wang, J., Yang, S., & Xu, Z. (2023). Talk like me: Exploring the feedback speech rate regulation strategy of the voice user interface for elderly people. *Frontiers in Psychology*, 14, 1119355. https://doi.org/10.3389/fpsyg.2023.1119355
> - Krause, J.C. & Panagiotopoulos, A.P. (2019). Speaking clearly for older adults with normal hearing. *JSLHR*, 62(12), 4534–4545. https://doi.org/10.1044/2019_JSLHR-H-19-0094

### 1.2 中文基准数据

| 场景 | 语速（字/分钟） | 来源 |
|------|---------------|------|
| 新闻联播播音标准 | 250–260字/分钟 | 中国广播电视标准，播音学教材 |
| 日常对话平均 | 160–200字/分钟 | 语速百科；zhihu播音分析 |
| 人耳辨析率上限 | 约280字/分钟 | 语速百科 |
| **老年人推荐** | **160–200字/分钟** | 综合听力老化与语速研究 |
| 认知评测指导语推荐 | **150–180字/分钟** | 本文综合推导（见下） |

**推导依据**：中文1字≈1音节，英文约1.5–2个音节/词。英文推荐老年人≤150 wpm对应中文约225字/分钟（过快）。考虑老年人汉语理解速度普遍低于年轻人，结合"正常对话下限"（160字/分钟）和"复杂指令放慢"原则，认知评测**指导语推荐150–180字/分钟**，核心规则说明处降至**120–150字/分钟**。

> 文献：
> - 百度百科-语速. https://baike.baidu.com/item/%E8%AF%AD%E9%80%9F/10857126
> - 知乎-广播新闻语速分析. https://zhuanlan.zhihu.com/p/139286167
> - Lee, J.Y. (2015). Age-related changes in cognition and speech perception. *J Audiol Otol*, 19(1), 7–13. https://doi.org/10.7874/jao.2015.19.1.7（PMC: [PMC4491939](https://pmc.ncbi.nlm.nih.gov/articles/PMC4491939/)）

### 1.3 执行标准

- **常规指导语**：**170字/分钟**（中文）/ **130 wpm**（英文参考）
- **核心规则说明**（如"看到数字3不要按"）：**140字/分钟**，降速20%
- **练习反馈**（如"对了/错了"）：**160字/分钟**
- 禁止：说话速度低于120字/分钟（过慢导致注意力涣散，[Autoppt speaking rate, 2026](https://autoppt.com/blog/ideal-speaking-rate-wpm/)证明<120 wpm导致认知游离）

## 2. 句子长度（Sentence Length）

### 2.1 文献数据

| 标准 | 上限 | 来源 |
|------|------|------|
| CDC Plain Language Guidelines | ≤20词/句（英文） | CDC Health Literacy, 2024 |
| AHRQ Health Literacy Guidelines | ≤15词/句均值 | AHRQ Plain Language |
| ODPHP Health Literacy Online | ≤20词/句 | ODPHP, 2022 |
| 每段限制 | 1个话题，≤5句 | CDC, 2024 |
| 每句限制 | 1个完整信息 | CDC Plain Language |
| 老年人记忆容量（Miller定律） | 5–9个信息组块 | Miller, 1956（Psych Review） |

**关键发现**：Miller（1956）的工作记忆"7±2"组块理论表明，老年人因工作记忆下降，实际容量接近下限5块，因此单句信息量应≤5个独立内容单元。CDC建议的≤20词对应中文约15–18字（中文单词更短）。对于口语化的音频指令，应比书面材料更短——听者无法回溯。

> 文献：
> - CDC. (2024). Plain Language Materials & Resources. https://www.cdc.gov/health-literacy/php/develop-materials/plain-language.html
> - Miller, G.A. (1956). The magical number seven, plus or minus two. *Psychological Review*, 63(2), 81–97. https://doi.org/10.1037/h0043158
> - AHRQ Plain Language. https://www.ahrq.gov/policy/electronic/plain-writing/index.html

### 2.2 执行标准

- **普通说明句**：每句**≤15个中文字**（对应英文≤12词）
- **关键规则句**（核心指令）：每句**≤10个中文字**
- **每段/每步骤**：1个主题，≤3句话
- 禁止复合条件句（"如果…那么…否则…"）→ 拆成两句分开说

## 3. 用词规范（Vocabulary）

### 3.1 禁忌词与替代

| 类别 | 禁止使用 | 推荐替代 | 理由 |
|------|---------|---------|------|
| 专业术语 | "抑制反应""执行功能" | "控制自己""想一想再按" | 老年人无心理学背景 |
| 学术任务名 | "N-back""TMT""SART" | "图片记忆""连线""不要按" | 英文缩写陌生 |
| 被动语态 | "按钮被按下时" | "你按下按钮" | CDC主动语态原则 |
| 双重否定 | "不是不需要按" | "要按" | 老年人解码成本高 |
| 复合条件 | "如果颜色和形状都换了" | 拆分为两句 | 超出工作记忆容量 |
| 数字英文混写 | "N=3" "3-back" | "三张图片""记住三张" | 口语化数字 |
| 量词省略 | "记两个" | "记住两张图片" | 具体名词减歧义 |
| Elderspeak（幼稚化） | 过度简化/夸张语调 | 正常成人语气 | Shaw & Gordon, 2021（降低理解率）|

### 3.2 推荐用词清单

| 动作类别 | 推荐用词 |
|---------|---------|
| 视觉注意 | 看、盯着、注意、找 |
| 触屏操作 | 按、点、点击、轻触 |
| 记忆任务 | 记住、记清楚、记牢 |
| 判断任务 | 一样、不一样、相同、不同 |
| 等待 | 等一等、稍等、准备好了再… |
| 开始信号 | 现在开始、好，开始 |
| 结束信号 | 完成了、好的、做完了 |
| 鼓励语 | 不错、很好、继续、没关系 |

### 3.3 文献依据

- **CDC Plain Language**（2024）："Use words your audience knows"，用日常熟悉词汇，解释所有新词
- **Shaw & Gordon（2021）**：Elderspeak（夸张语调+幼稚词汇）**降低老年人理解率**，被评为不尊重。语法简化有益，但必须保持正常成人语调。
  > Shaw, C., & Gordon, J. (2021). Understanding elderspeak: An evolutionary concept analysis. *Innovation in Aging*, 5(3), igab023. https://doi.org/10.1093/geroni/igab023（PMC: [PMC8406004](https://pmc.ncbi.nlm.nih.gov/articles/PMC8406004/)）
- **PMC6044302**：Plain language = "能在第一次听到时就理解的内容"
  > Nutbeam, D. (2018). Plain language communication as a priority competency for medical professionals. *J Comm Healthcare*, 11(2), 91–94. https://doi.org/10.1080/17538068.2018.1436967（PMC: [PMC6044302](https://pmc.ncbi.nlm.nih.gov/articles/PMC6044302/)）

### 3.4 执行标准

- 所有指导语词汇目标：**小学三年级口语水平**（日常对话常用词3000以内）
- 每个新概念首次出现时**口头解释一次**（如"'一样'就是图案和颜色都没变"）
- 禁止任何英文缩写或术语进入音频

## 4. 停顿设计（Pause Duration）

### 4.1 文献数据

| 停顿类型 | 推荐时长 | 来源 |
|---------|---------|------|
| 自然语句内部 | 250–400 ms | 语言学研究（Zellner, 1994） |
| 句间停顿（正常语音） | 500–600 ms | Speechgen TTS研究；BYU感知研究 |
| 句间最优（理解提升） | **300–600 ms** | ScienceDaily（Levitan研究，2015） |
| 关键信息前停顿 | **1.0–1.5 s** | VUI设计规范（Parallelhq, 2026） |
| 提问后停顿 | **500 ms** | VUI Design Best Practices（Designlab） |
| 步骤之间 | **2.0 s** | Boyd et al., 2015（PMC5424854） |
| 等待用户回应超时 | **8–10 s** | VUI设计规范（Parallelhq, 2026） |
| 老年人处理额外需求 | 比正常对话多 | ASHA Leader, 2005 |

**关键发现**：
1. ScienceDaily（2015）引用Levitan等研究：半秒停顿的句子**显著比**无停顿和过长停顿（4秒）的句子更容易理解。
2. Boyd等（2015）的痴呆患者多步骤任务研究发现，下一步按钮**延迟几秒后**才出现，防止用户在处理当前指令时被导航分心——支持步骤间≥2秒缓冲。
3. ASHA Leader（2005）明确指出：在句子、从句、主要思想单元末尾停顿"一两拍"有助于老年人理解和记忆。
4. Windle等（2023）：老年人听觉处理中"声音间隙（gaps）"识别能力随年龄下降，因此停顿必须**足够清晰、足够长**才能让认知追上语音。
   > Windle, R., Dillon, H., & Heinrich, A. (2023). A review of auditory processing and cognitive change during normal ageing. *Frontiers in Neurology*, 14, 1122420. https://doi.org/10.3389/fneur.2023.1122420（PMC: [PMC10318159](https://pmc.ncbi.nlm.nih.gov/articles/PMC10318159/)）

> 文献：
> - ScienceDaily. (2015). Pauses can make or break a conversation. https://www.sciencedaily.com/releases/2015/09/150930110555.htm
> - Boyd, H.C., et al. (2015). Using simple technology to prompt multistep tasks in the home for people with dementia. *Dementia*, 16(4), 424–442. https://doi.org/10.1177/1471301215602417（PMC: [PMC5424854](https://pmc.ncbi.nlm.nih.gov/articles/PMC5424854/)）
> - VUI Design Principles. (2026). Parallelhq. https://www.parallelhq.com/blog/voice-user-interface-vui-design-principles

### 4.2 停顿位置分类

| 位置 | 时长 | 说明 |
|------|------|------|
| 句子内部（逗号） | **0.4 s** | 呼吸感，不打断 |
| 句间（句号）| **0.8 s** | 正常节奏 |
| 关键规则前（如"注意！"后）| **1.2 s** | 引起注意，为下一句做准备 |
| 关键规则后（说完规则后）| **1.5 s** | 老年人工作记忆编码时间 |
| 步骤切换（"好，现在..."前）| **2.0 s** | 完成认知闭合 |
| 指令与行动之间（"现在请按..."后）| **3.0 s** | 给用户完成动作的时间 |
| 练习题开始前 | **2.0 s** | 确认准备好 |

### 4.3 执行标准

用SSML（Speech Synthesis Markup Language）实现：
```xml
<speak>
  现在开始说明任务规则。
  <break time="0.8s"/>
  注意，
  <break time="1.2s"/>
  看到数字三的时候，不要按按钮。
  <break time="1.5s"/>
  其他数字，都要按。
  <break time="2.0s"/>
  好，我们先来练习一下。
  <break time="2.0s"/>
</speak>
```

## 5. 重复策略（Repetition）

### 5.1 文献数据

| 参数 | 推荐值 | 来源 |
|------|-------|------|
| 间隔重复效果优于集中重复 | 老年人更显著 | Maddox & Balota, 2015（PMC4480221） |
| 最优重复次数（面-名学习） | **3次间隔**优于1次，5次与3次无显著差异 | Maddox & Balota, 2015 |
| 间隔学习vs集中学习（1月后保留率） | 间隔组显著更高 | Caffrey & Commins, 2023（PMC9892402） |
| MCI患者间隔重复改善记忆 | 20人中19人提升>10% | JMIR Formative Research, 2024 |
| MIS认知评估标准 | 关键词可重复**至多3次** | Alzheimer Foundation MIS Protocol |
| 记忆再巩固（重新呈现关键信息） | 重复激活强化长期记忆 | 多项spacing effect综述 |

**关键发现**：Maddox & Balota（2015）在老年人（vs年轻人）对比实验中发现，**间隔重复3次**比集中重复效果显著更好，且老年人的spacing效应**大于年轻人**（即老年人从间隔重复中获益更多）。增加到5次并无额外收益。对于认知评测指导语，核心规则应在**3个不同时间点**呈现。

> 文献：
> - Maddox, G.B., & Balota, D.A. (2015). Retrieval practice and spacing effects in young and older adults. *Memory & Cognition*, 43(5), 760–774. https://doi.org/10.3758/s13421-014-0499-6（PMC: [PMC4480221](https://pmc.ncbi.nlm.nih.gov/articles/PMC4480221/)）
> - Caffrey, M., & Commins, S. (2023). Preservation of long-term memory in older adults using a spaced learning paradigm. *European Journal of Ageing*, 20, 2. https://doi.org/10.1007/s10433-023-00750-5（PMC: [PMC9892402](https://pmc.ncbi.nlm.nih.gov/articles/PMC9892402/)）
> - JMIR Formative Research. (2024). Algorithmic spaced retrieval in Alzheimer disease. https://formative.jmir.org/2024/1/e51943

### 5.2 指导语中的重复架构

每个范式核心规则在**3个时间节点**出现（spacing effect实现）：

| 节点 | 出现形式 | 时机 |
|------|---------|------|
| T1（初次）| 完整规则描述 | 任务说明阶段 |
| T2（练习前）| 精简版提醒（1句话）| 练习题开始前 |
| T3（正式前）| 最简提醒 + 确认语 | 正式测试开始前 |

**示例（SART）**：
- T1（说明）："当数字是三的时候，不要按按钮。其他所有数字，都要按。"
- T2（练习前）："记得，看到三不要按。"
- T3（正式前）："好，正式开始了。三——不按，其他——都按。"

### 5.3 执行标准

- 每个范式核心规则**恰好重复3次**（T1完整+T2精简+T3最简），不超过5次（过多重复干扰）
- 练习失败时（错误率>50%）：用**换一种措辞**再说一遍规则，不是逐字重复
- 禁止：在同一段音频内连续重复同一句话（≤15秒内重复=被试觉得被当幼儿对待）

## 6. 语气设计（Tone）

### 6.1 文献数据

| 发现 | 依据 |
|------|------|
| 刻板印象威胁（stereotype threat）使老年人认知测试表现下降 | Barber et al., 2015；Chasteen et al., 2005 |
| 威胁条件vs非威胁条件：MMSE/MoCA分数显著差异 | Barber, 2020（PMC9415413） |
| 威胁条件：70%老年人MMSE得分低于痴呆截止分 vs 非威胁14% | Impact of Stereotype Threat, 2023（PMC10614630） |
| "损失框架"（不做错误而非"得分"）消除威胁效应 | Barber et al., 2015（η²p=.31 vs .06） |
| Elderspeak（幼稚化语气）降低理解且被感知为不尊重 | Shaw & Gordon, 2021（PMC8406004） |
| "临床检查"框架比"大学研究"框架表现更差 | Schlemmer & Desrichard, 2018（via Barber, 2020） |
| 印象形成任务框架比记忆测试框架提升~15%正确率 | Chasteen et al., 2005（PMC1751474） |

**关键发现**：
1. **绝对不能**将任务描述为"记忆测试""检测认知能力"——这触发刻板印象威胁，使表现骤降。
2. **推荐中性/任务框架**：描述任务步骤，不强调能力测量。
3. Barber等（2015）发现"损失规避框架"（"避免错误"而非"争取得分"）能完全消除威胁效应（η²p从.31降至.06，p=.34不显著）。
4. **温和但成人化**的语气是最佳选择——不幼稚化，不临床化，类似"友好向导"。

> 文献：
> - Barber, S.J., Mather, M., & Gatz, M. (2015). How stereotype threat affects older adults' performance on clinical assessments. *Journal of Gerontology B*, 70(6), 891–900. https://doi.org/10.1093/geronb/gbv009（PMC: [PMC4841160](https://pmc.ncbi.nlm.nih.gov/articles/PMC4841160/)）
> - Barber, S.J. (2020). Applied implications of age-based stereotype threat. *JARMAC*, 9(3), 274–285. https://doi.org/10.1016/j.jarmac.2020.05.002（PMC: [PMC9415413](https://pmc.ncbi.nlm.nih.gov/articles/PMC9415413/)）
> - Chasteen, A.L., et al. (2005). How feelings of stereotype threat influence older adults' memory performance. *Experimental Aging Research*, 31(3), 235–260. https://doi.org/10.1080/03610730590948177（PMC: [PMC1751474](https://pmc.ncbi.nlm.nih.gov/articles/PMC1751474/)）

### 6.2 具体语气原则

| 原则 | 正确做法 | 错误做法 |
|------|---------|---------|
| 不触发威胁 | "接下来我们一起做一个练习" | "测试您的记忆力" |
| 损失框架 | "尽量避免按错" | "看您能得几分" |
| 成人化 | "您准备好了吗" | "来，宝贝，准备好了嘛" |
| 任务化描述 | "这道题，看到数字3就不要按" | "现在检验一下您的反应控制能力" |
| 规范化错误 | "没关系，继续" / "很正常，再试一次" | 沉默 / "错了" |
| 不制造时间压力 | 不提时间 | "时间快到了！快点！" |
| 尊称使用 | "您" | "你"（针对65+老人） |
| 完成鼓励 | "做得很好，休息一下" | 无反馈直接进下一项 |

### 6.3 语气原型

**推荐语气模型**：温和的任务向导（Warm Task Guide）
- 开场："现在我来告诉您接下来要做什么。请放松，按您自己的节奏来就好。"
- 过渡："好，这一段完成了。接下来换一个练习。"
- 错误处理："没关系，我们再来一遍。"
- 任务前确认："准备好了吗？准备好了，就按开始。"
- 完成鼓励："很好，这部分完成了。"

### 6.4 执行标准

- **禁用词**：记忆力、认知、测试能力、聪明、老年痴呆相关词汇
- **必用词**：练习、任务、步骤（而非"测试""考试"）
- **语气基调**：温和引导者，不是考官，不是医生
- **用"您"**（不用"你"）

## 7. 中文特殊考虑（Chinese-Specific）

### 7.1 普通话标准

| 维度 | 要求 | 依据 |
|------|------|------|
| 发音标准 | 标准普通话，声调清晰 | 老年人对声调感知依赖（对比英语） |
| 发音精确 | 不吞字，每个音节完整 | Windle et al., 2023：老年人依赖语音包络（ENV）解析语音 |
| 儿化音 | 避免（非北方方言被试可能混淆） | 浙江受试者普遍使用吴语背景 |
| 方言混入 | 禁止 | 标准化测评要求一致性 |
| 数字读法 | 口语读法（"三"非"3"，"十五"非"15"）| 老年人对书面数字符号阅读速度慢 |
| 停顿节奏 | 按语义组块而非字数断句 | 中文句间停顿应在语义完整处 |

### 7.2 TTS引擎选择

| 引擎 | 优点 | 缺点 | 适用性 |
|------|------|------|-------|
| **CosyVoice（通义/阿里）** | 自然度高，支持SSML，国内可用，免费额度大 | 依赖阿里云服务 | **首选** |
| **Microsoft Azure TTS（晓晓）** | 情感声音支持，温和女声，老年友好语气 | 海外服务，需翻墙或企业账号 | **备选** |
| Google TTS | 质量高 | 国内不可用 | 不适用 |
| 百度TTS | 国内可用 | 自然度较低，机械感强 | 不推荐 |
| 离线本地TTS | 无网络依赖 | 质量差，无SSML支持 | 紧急备用 |

**推荐音色特征**：
- 女声（研究显示女声在老年人中接受度更高，感知为更温和）
- 成熟女声（避免偏年轻/儿童化的音色）
- 语速可调（支持SSML `<prosody rate>`参数）
- 有情感标注支持（如Azure晓晓的"gentle""calm"情感）

### 7.3 SSML实现示例（CosyVoice/Azure）

```xml
<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis"
       xml:lang="zh-CN">
  <voice name="zh-CN-XiaoxiaoNeural">
    <prosody rate="-20%" pitch="-5%">
      现在我来说明这个练习的规则。
      <break time="0.8s"/>
      <emphasis level="moderate">注意</emphasis>，
      <break time="1.2s"/>
      看到数字三的时候，不要按按钮。
      <break time="1.5s"/>
      其他所有数字，都要按。
      <break time="2.0s"/>
      好，我们先练习几次。
      <break time="2.0s"/>
    </prosody>
  </voice>
</speak>
```

### 7.4 语音文件技术规格

| 参数 | 推荐值 |
|------|-------|
| 格式 | WAV（PCM 16-bit）或 MP3（192kbps+） |
| 采样率 | 44100 Hz（高保真）或 22050 Hz（最低） |
| 声道 | 单声道（Mono）—— 避免立体声混淆定位 |
| 响度归一化 | -14 LUFS（与设备系统音量一致性） |
| 文件命名 | `{paradigm}_{section}_{lang}.wav`（如 `sart_rule_zh.wav`） |
| 存储位置 | 实验目录 `audio/` 子目录 |

### 7.5 执行标准

- 使用**CosyVoice成熟女声**（首选），Azure晓晓（备选）
- SSML中 `rate="-20%"` 对应约170字/分钟起始速率
- 所有音频文件提前生成并本地存储（不依赖实时TTS网络请求）
- 录音完成后人工检查：用65岁以上测试者聆听并反馈是否清晰

## 执行标准总表（直接可用）

| 维度 | 标准值 | 文献来源 |
|------|-------|---------|
| 常规指导语语速 | **170字/分钟**（中文）| Hux et al., 2019；Wang et al., 2023 |
| 核心规则语速 | **140字/分钟**（降速20%）| 老年人认知加工理论 |
| 每句字数上限 | **≤15字**（普通）/ **≤10字**（关键规则）| CDC Plain Language, AHRQ |
| 每步骤句数 | **≤3句**，1个主题 | CDC Plain Language |
| 句间停顿 | **0.8 s** | Speechgen；BYU感知研究 |
| 关键信息前停顿 | **1.2 s** | VUI设计规范 |
| 关键信息后停顿 | **1.5 s** | Windle et al., 2023 |
| 步骤切换停顿 | **2.0 s** | Boyd et al., 2015 |
| 等待行动停顿 | **3.0 s** | VUI标准规范 |
| 核心规则重复次数 | **3次**（T1完整+T2精简+T3最简）| Maddox & Balota, 2015 |
| 重复时间间隔 | **间隔分布**（说明→练习前→正式前）| Spacing Effect；Caffrey & Commins, 2023 |
| 语气框架 | **温和任务向导**，不触发能力评价 | Barber et al., 2015 |
| 词汇水平 | **小学三年级口语**，无英文缩写 | CDC；Shaw & Gordon, 2021 |
| 称呼 | **"您"**（不用"你"）| 文化礼貌规范 |
| 禁用词 | 记忆力/认知能力/测试/考试/得分/老年痴呆 | Barber, 2020 |
| 语音 | **CosyVoice/Azure晓晓成熟女声** | Azure Neural TTS文档 |
| TTS参数 | rate="-20%"，SSML控制停顿 | SSML W3C标准 |
| 音频格式 | WAV 44100Hz 单声道 -14 LUFS | 音频工程标准 |
