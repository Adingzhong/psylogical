## 一、协作流程

```
1. Claude 先分析代码+反馈+开发文档，输出：
   - 范式完整流程图（哪些位置放音频）
   - 每张图的步骤拆分 + 语音文字初稿
   → 用户审核文字，修改措辞

2. 图片准备：
   - UX实习生出的图可直接用，但需检查是否与代码实际行为一致
   - 如需新图/改图：用 Gemini(banana API) 生成无文字底图 → 用户PPT加文字
   - 辅助素材（手指、图标等）单独生成，用户PPT拼装

3. Claude 生成逐句音频 + 搭建 region-editor 页面
   → 用户用 region-editor 调整红框坐标 + 修改字幕文字
   → 用户复制配置发回

4. Claude 集成代码 + Playwright验证截图
   → 用户浏览器实测 → 反馈修bug

5. 用户验收数据（下载CSV检查字段完整性）
   → 确认OK → commit → 下一个范式
```

## 二、踩坑记录（必读）

### 音频相关
- **model参数必须和voice_id匹配**：voice_id是v3.5-plus创建的，model就必须填`cosyvoice-v3.5-plus`，填`cosyvoice-v2`会418
- **逐句单独生成**：不要合成一段长音频再用时间戳切分，时间戳对不齐。一句一个wav文件
- **音频互斥**：同一范式中如果多处播放音频（如演示阶段），必须停掉上一个再播下一个，否则重叠
- **server/main.py 需要 mount /audio**：`app.mount("/audio", StaticFiles(directory=str(ROOT / "audio")), name="audio")`，已加，新窗口不用再加

### voice-guide.js 组件
- **不要autoplay**：用户点击按钮后才播放音频，避免浏览器拦截
- **覆盖按钮全程盖住图片原"继续"**：初始"▶ 播放"→播放中灰色"播放中..."→播完"开始练习"，全程用我们的按钮遮住图片原按钮
- **lines数组**：一个红框可以播放多句话。格式 `{ region: {...}, lines: [{ audio, subtitle }, ...] }`
- **进度计数器隐藏**：VoiceGuide显示时自动隐藏`#_nback_progress`，关闭时恢复。其他范式如有类似进度条需同样处理
- **字幕**：31px bold，已在CSS中固定

### 图片相关
- **UX图片和代码行为可能不一致**：例如B3图上画星星，实际代码用橙色边框。必须先看代码确认，语音描述要和代码实际一致
- **Gemini生成图片**：擅长整体风格，但精确定位（"黑点在正中心"）控制力弱。复杂修改建议拆成素材让用户PPT拼装
- **图片文字由用户PPT加**：Claude生成无文字底图+布局说明，用户加文字更快更准

### 代码集成
- **不要改练习通过率**（用户明确说了）
- **不要显示练习次数**给被试（"第X/X次"去掉）
- **练习反馈1500ms**（不是2000ms）
- **每个block正式阶段开始前要reset进度计数器**，用实际的main trial count，不是练习的count
- **每个block结束都要有注意力探针**（B2之前漏了）
- **test页面**：每个范式做独立test页面（test_b2.html等），避免每次从头跑

### 文案风格
- **图片上的字精简**（一行标题级），详细的留给语音播报
- **语音不说颜色**（按钮都是灰色）：说"点击一致按钮"不说"点击绿色的一致"
- **每句话短**：不超过20字，长句拆成多句
- **容易混淆的概念要举具体例子**：如"相似"→"比如沙发上多了一个抱枕"
- **每个block结尾都说"有不清楚的可以问工作人员"**：老人后面越来越不敢问
- **多block范式的后续block开头**：要和前一个block做对比说明，如"这次规则与上一个任务有所不同"

## 四、voice-guide.js API（v3，已定稿）

```javascript
// 逐句播放 + 红框高亮 + 字幕 + 覆盖按钮
await VoiceGuide.show({
  image: 'img/rules.png',
  btnRegion: { x: '80%', y: '5%', w: '15%', h: '8%' },  // 覆盖图片"继续"按钮
  buttonText: '开始练习',
```

## 五、TTS生成代码模板

```python
import os
os.environ.setdefault('DASHSCOPE_API_KEY', os.environ.get('DASHSCOPE_API_KEY', ''))
from dashscope.audio.tts_v2 import SpeechSynthesizer, AudioFormat

VOICE_ID = 'cosyvoice-v3.5-plus-zjuguide-cd12059797c74840aaf1b7fe23ea8c06'
MODEL = 'cosyvoice-v3.5-plus'  # 必须和voice_id的target_model一致！
FMT = AudioFormat.WAV_22050HZ_MONO_16BIT

sentences = [
    ('s01', '第一句话'),
    ('s02', '第二句话'),
]

for name, text in sentences:
    synth = SpeechSynthesizer(model=MODEL, voice=VOICE_ID, format=FMT, speech_rate=1.0)
    audio = synth.call(text)
    with open(f'{name}.wav', 'wb') as f:
        f.write(audio)
```

## 六、region-editor 创建与使用

### 已有的editor
- N-back: `web-battery/paradigms/nback/region-editor.html`（支持3张图切换）
- 空间导航: `web-battery/paradigms/visuospatial/region-editor.html`（支持2张图切换）

### 给新范式创建editor

**最快方式**：复制空间导航的editor（单图最简），改3处：

```bash
cp web-battery/paradigms/visuospatial/region-editor.html web-battery/paradigms/{新范式}/region-editor.html
```

然后编辑新文件，改：
1. `<img id="mainImg" src="img/rules.png">` → 改成实际图片路径
2. `<select id="imageSelect">` → 改选项为这个范式的图片列表（单图范式可去掉select）
3. `defaultStepsMap` → 改成这个范式的默认步骤和语音文字

**如果是多图范式**（如VSTMB有3个block图），参考N-back的editor，在`defaultStepsMap`里给每张图配独立的steps数组。

### editor核心结构（给新窗口理解用）

```javascript
// 默认步骤配置 — 每张图一组steps
const defaultStepsMap = {
  'img/rules.png': [
    { x: 5, y: 10, w: 25, h: 50, subtitle: '第一句话\n第二句话（同一个红框）' },
    { x: 35, y: 10, w: 55, h: 40, subtitle: '第三句话' },
    // ...
  ],
  'img/block2.png': [ ... ],  // 多图时
};

// "继续"按钮覆盖位置
let btnOverlay = { x: 80, y: 4, w: 15, h: 8 };
```

### editor输出格式

用户调完坐标后，点"📋 复制代码"得到的格式：
```
rules: [
  { region: { x: '5%', y: '10%', w: '25%', h: '50%' }, lines: ['第一句话', '第二句话'] },
  { region: { x: '35%', y: '10%', w: '55%', h: '40%' }, lines: ['第三句话'] },
]
btnOverlay: { x: '80%', y: '4%', w: '15%', h: '8%' }
```

Claude拿到这个后：
1. 根据lines里的文字生成逐句音频
2. 在范式JS代码中写入VoiceGuide.show()配置
3. 每个line对应一个 `{ audio: '路径', subtitle: '文字' }`

### 用户操作
1. 打开 `http://localhost:8082/paradigms/{paradigm}/region-editor.html`
2. 下拉选择图片（如有多张）
3. 左侧面板：每步一张卡片，textarea里每行一句话（多行共享同一个红框）
4. 拖拽红框调位置，拖四角调大小
5. 蓝色虚线框 = 覆盖"继续"按钮位置
6. 底部"📋 复制代码"→ 发给Claude
7. "📝 复制语音文本"→ 给Claude生成音频
