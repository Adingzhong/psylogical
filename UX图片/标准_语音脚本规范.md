## 1. 语速

| 场景 | 中文语速 | SSML参数 |
|------|---------|---------|
| 常规说明 | 170字/分钟 | `rate="-20%"` |
| 核心规则 | 140字/分钟 | `rate="-30%"` |
| 练习反馈 | 160字/分钟 | `rate="-23%"` |
| 鼓励语 | 170字/分钟 | `rate="-20%"` |

**底线**：不低于120字/分钟（过慢导致注意力涣散）

---

## 2. 句子长度

| 类型 | 上限 | 示例 |
|------|------|------|
| 普通说明 | ≤15字 | "屏幕上会出现一排箭头。" (10字) |
| 关键指令 | ≤10字 | "只看中间那个。" (6字) |
| 禁止 | 复合条件句 | ~~"如果箭头朝左且颜色是黄色就按左键"~~ |

**规则**：一句话只说一件事。需要说两件事就拆成两句。

---

## 3. 用词

### 禁用词

| 禁用 | 替代 | 理由 |
|------|------|------|
| 记忆力 | — | 刻板印象威胁（Barber 2015） |
| 认知能力 | — | 同上 |
| 测试/考试 | 练习/任务 | 同上 |
| 得分/成绩 | — | 制造压力 |
| 错误！ | 再试一次 / 没关系 | 焦虑 |
| N-back/TMT/SART | 图片记忆/连线/数字 | 英文缩写陌生 |
| 抑制反应 | 忍住不按 | 口语化 |
| 交替 | 轮流 | 老年人更易理解 |
| 搭配交换 | 颜色换了位置 | 具体化 |

### 推荐动词

| 类别 | 用词 |
|------|------|
| 视觉 | 看、盯着、注意、找 |
| 触屏 | 按、点、轻触 |
| 记忆 | 记住、记清楚 |
| 判断 | 一样、不一样 |
| 等待 | 等一等、准备好了再… |
| 鼓励 | 不错、很好、没关系、继续 |

### 称呼
- **用"您"**，不用"你"
- 不用"爷爷""奶奶"等称谓（Elderspeak，Shaw & Gordon 2021）

## 4. 停顿

### SSML实现

```xml
<speak>
  现在来说明任务规则。
  <break time="0.8s"/>          <!-- 句间 -->
  <emphasis>注意</emphasis>，
  <break time="1.2s"/>          <!-- 关键信息前 -->
  看到数字三，不要按按钮。
  <break time="1.5s"/>          <!-- 关键信息后 -->
  其他所有数字，都要按。
  <break time="2.0s"/>          <!-- 步骤切换 -->
  好，我们先来练习一下。
  <break time="3.0s"/>          <!-- 等待行动 -->
</speak>
```

### 停顿位置速查

| 位置 | 时长 | SSML |
|------|------|------|
| 逗号 | 0.4s | `<break time="0.4s"/>` |
| 句号 | 0.8s | `<break time="0.8s"/>` |
| "注意"后 | 1.2s | `<break time="1.2s"/>` |
| 规则说完后 | 1.5s | `<break time="1.5s"/>` |
| 换步骤前 | 2.0s | `<break time="2.0s"/>` |
| "请按按钮"后 | 3.0s | `<break time="3.0s"/>` |
| 练习题开始前 | 2.0s | `<break time="2.0s"/>` |

## 5. 重复策略

### 3次间隔重复

| 节点 | 形式 | 字数 | 时机 |
|------|------|------|------|
| T1 | 完整规则描述 | 30-50字 | 规则说明阶段 |
| T2 | 精简提醒 | 10-15字 | 练习开始前 |
| T3 | 最简+确认 | 15-20字 | 正式测试前 |

### 示例（Flanker）

- **T1**："屏幕上会出现五个箭头排成一行。请只看中间那个箭头。它朝左，您就按左边按钮。它朝右，您就按右边按钮。两边的箭头不要管它。"
- **T2**："记住，只看中间箭头的方向。"
- **T3**："中间朝左按左，朝右按右。准备好了吗？"

### 重试换措辞

- 第1次重试：用不同说法重述（"两边不要管"→"眼睛盯住正中间"）
- 禁止：同一段音频内15秒内逐字重复同一句话
- 只有1次重试机会，所以重试版要把换说法+类比合并在一起

## 6. 语气

### 原则

**角色定位：温和的任务向导（Warm Task Guide）**

不是考官，不是医生，不是幼儿园老师。

### 框架

| 原则 | ✅ 正确 | ❌ 错误 |
|------|--------|--------|
| 不触发威胁 | "接下来一起做个练习" | "测试您的记忆力" |
| 任务化描述 | "这道题，看到3就不按" | "检验反应控制能力" |
| 规范化错误 | "没关系，再试一次" | 沉默 / "错了" |
| 不制造压力 | （不提时间） | "时间快到了！" |
| 成人化语气 | "您准备好了吗" | "来，准备好了嘛~" |

### 固定话术模板

| 场景 | 话术 |
|------|------|
| 开场 | "现在来说明接下来要做什么。请放松，按您自己的节奏来。" |
| 过渡 | "好，这一段完成了。接下来换一个练习。" |
| 错误反馈 | "没关系，我们再来一遍。" |
| 正式前 | "准备好了吗？准备好了，就按开始。" |
| 完成 | "很好，这部分完成了。" |
| 全部结束 | "所有任务都完成了，辛苦您了。" |

## 7. TTS技术规格

### 引擎

| 优先级 | 引擎 | 音色 | SSML支持 |
|--------|------|------|---------|
| **首选** | CosyVoice（通义/阿里） | 成熟女声 | ✅ 完整 |
| 备选 | Azure TTS（晓晓） | gentle情感 | ✅ 完整 |
| 紧急 | 人工录音 | — | N/A |

### 音频文件规格

| 参数 | 值 |
|------|---|
| 格式 | WAV (PCM 16-bit) |
| 采样率 | 44100 Hz |
| 声道 | Mono（单声道） |
| 响度 | -14 LUFS |
| 命名 | `{paradigm}_{section}_{lang}.wav` |
| 存储 | `web-battery/audio/{paradigm}/` |

### 命名规范

```
flanker_t1_rule_zh.wav      — Flanker T1规则说明
flanker_t2_reminder_zh.wav  — Flanker T2精简提醒
flanker_t3_confirm_zh.wav   — Flanker T3正式前确认
flanker_retry_zh.wav        — Flanker 重试换措辞
flanker_feedback_wrong_zh.wav — Flanker 错误反馈
flanker_feedback_done_zh.wav  — Flanker 练习完成
```

## 脚本编写模板

每个范式脚本文件遵循此格式：

```markdown
# [范式名] 语音脚本

## 元信息
- 总时长估算：XX秒（T1+T2+T3+反馈，不含练习时间）
- 对应UX图：X范式.png
- 练习试次：X次
- 通过标准：75%

## T1 规则说明
[语音文字，含<break>标记]
字数：XX字 | 预计时长：XX秒

## 分步练习引导（如有②阶段）
### 步骤1
- 语音：[文字]
- 屏幕：[展示内容]
- 用户操作：[按什么/不操作]
### 步骤2
...

## T2 练习前提醒
[1句精简版] | 字数：XX字

## T3 正式前提醒
[最简版 + 确认] | 字数：XX字

## 错误反馈
[通用反馈语]

## 重试版（第1次）
[换措辞重述规则]

## 音频文件清单
- [ ] {paradigm}_t1_rule_zh.wav
- [ ] {paradigm}_t2_reminder_zh.wav
- [ ] {paradigm}_t3_confirm_zh.wav
- [ ] {paradigm}_retry_zh.wav
- [ ] {paradigm}_feedback_wrong_zh.wav
- [ ] {paradigm}_feedback_done_zh.wav
```
