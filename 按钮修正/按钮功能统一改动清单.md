## 二、需要统一的功能（按优先级）

### P0：html, body 全局 touch-action: none

**一行修复。** 当前 `touch-hardening.js:86-89` 的 html, body CSS 缺少 `touch-action: none`，导致左手搭屏+右手按按钮时触发双指缩放+按钮点击被吞。

```diff
  'html, body {\n' +
  '  -webkit-touch-callout: none !important;\n' +
  '  overscroll-behavior: none !important;\n' +
+ '  touch-action: none !important;\n' +
  '}\n' +
```

### P1：correctRT() 扩展 — 输出漂移指标

当前 correctRT() 只输出 `rt`, `rt_original`, `rt_hold`。扩展为同时输出：

```
rt              — pointerdown 时刻（认知决策时间）
rt_original     — click 时刻（jsPsych 原始值）
rt_hold         — 按压时长（pointerup - pointerdown）
drift_max       — 按压期间离初始触点最大位移(px)
drift_path      — 手指运动轨迹总长(px)
drift_end       — 松手时离起点距离(px)
```

需要在 touch-hardening.js 的 pointerdown/pointermove/pointerup 流程中增加漂移记录。

### P2：缺失范式补上 correctRT()

| 范式 | 改动 |
|------|------|
| 视空间 | canvas 改用 pointerdown 记 RT + pointerup 执行 → 调 correctRT() |
| 人际距离 | setupButton 的 trackRT 改为 true → 调 correctRT() |
| 语音 | stop 按钮改为 setupButton() → 调 correctRT() |
| 画钟 | 控制按钮接入 setupButton()（低优先级，非 RT 关键） |

### P3：视觉反馈参数统一

所有走 TouchHardening 的按钮统一为：
- 按下：opacity 0.80, scale 0.92, transition 0.06s
- 确认：白色边框光晕, 300ms

各范式自己的 CSS :active 需要与 TouchHardening 的 .elderly-pressing 对齐，避免两套反馈叠加或冲突。

当前冲突示例：
- SART 的 :active 用 scale(0.95)，TouchHardening 的 .elderly-pressing 用 scale(0.92) → 如果同时触发则叠加为 0.95×0.92=0.874
- Flanker 的 :active 用 scale(0.96)，与 .elderly-pressing 也冲突

解决方案：各范式移除自定义的 :active 缩放，统一由 TouchHardening 的 .elderly-pressing 处理。

### P4：SART 的 correctRT 冗余处理

SART 在 pointerdown 时手动记录 RT（`_sartResponseRT = performance.now() - _sartTrialStart`），然后在 on_finish 中又调用 `TouchHardening.correctRT(data)`。

因为 SART 不走 TouchHardening 的按钮包装（使用自己的 pointerdown 监听器），`window.__touchRT` 为 null，correctRT() 实际上什么也不做（第一行 `if (!window.__touchRT) return;` 直接返回）。

这不是 bug，只是冗余代码。保留无害，但应在注释中说明。

## 三、改动顺序

```
第一步：touch-hardening.js 升级
  ├── P0: html,body touch-action: none（1行）
  ├── P1: pointermove 记录漂移数据
  └── P1: correctRT() 扩展输出 drift 字段

第二步：各范式接入统一
  ├── P2: 视空间 → pointerdown RT + correctRT()
  ├── P2: 人际距离 → trackRT=true + correctRT()
  ├── P2: 语音 → setupButton + correctRT()
  └── P4: SART → 加注释说明 correctRT 冗余

第三步：视觉反馈统一（样式，后做）
  ├── P3: 各范式移除自定义 :active 缩放
  ├── P3: 统一由 .elderly-pressing 处理按下效果
  └── P3: 统一由 .elderly-confirmed 处理确认效果

第四步：按钮尺寸/形状/颜色统一（样式，最后做）
  ├── 所有响应按钮 → 圆角矩形 240×120px
  ├── VSTMB 圆形 → 圆角矩形
  ├── 人际距离 130px → 加大
  └── 颜色统一为中灰 #A0A0A0
```
