# VSTMB 视觉短期记忆绑定实验程序

## 快速开始

1. **双击运行**: `运行实验.bat`
2. **输入信息**: 手机号码（必填）、被试ID（可选）
3. **开始实验**

## 文件结构

```
范式程序_正式版/
├── 运行实验.bat              # 双击运行实验
├── main.py                   # 主程序
├── experiment_manager.py     # 实验流程管理
├── stimulus_manager.py       # 刺激呈现管理
├── data_manager.py           # 数据记录管理
├── config.json               # 配置文件
├── 检查版本.py               # 版本检查工具
├── 使用说明.txt              # 详细使用说明
├── README.md                 # 本文件
└── data/                     # 数据保存文件夹
```

## 实验参数

- **图片尺寸**: 96px × 96px（正方形）
- **背景色**: RGB(191, 191, 191)
- **练习试次**: 4次/条件
- **正式试次**: 18次/条件
- **实验条件**: Object, Color, Binding

## 数据文件

实验数据保存在 `data/` 文件夹：
- `VSTMB_被试ID_时间戳.csv` - 详细试次数据
- `VSTMB_被试ID_时间戳_summary.json` - 汇总统计

## 注意事项

1. 必须使用PsychoPy的Python环境运行
2. 实验图片必须放在上级目录的"实验图片"文件夹
3. 按ESC键可随时退出并保存部分数据
