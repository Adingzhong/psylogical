# 练习反馈统一标准

> 日期：2026-04-09
> 依据：`UX图片/标准_练习阶段.md` + `UX图片/标准_语音脚本规范.md`
> 核心原则：**非惩罚性、中性、鼓励性**

---

## 一、现状问题

| 范式 | 当前正确反馈 | 当前错误反馈 | 违反标准？ |
|------|------------|------------|----------|
| Flanker | **无** | 红X 72px + "正确答案: ←(左)" | ❌ 红叉违规 + 无正确反馈 |
| SART | 无 | 红字 "X 数字3别按!" / "X 记得按键!" | ❌ 红叉违规 + 语气急 |
| N-back | 绿 "✓ 正确" 56px | 红 "✗ 错误" 56px | ❌ "错误"二字违规 |
| VSTMB | 绿 "✓ 正确" 56px | 红 "✗ 错误" 56px | ❌ 同上 |

**标准要求**：
- ❌ 不用红叉/警告音
- ❌ 不说"错误！"
- ✅ 改为"再试一次"或"没关系"
- ✅ 正确时给轻微正反馈（绿色闪烁或简短提示）

## 二、统一反馈方案

### 视觉参数

| 参数 | 统一值 | 说明 |
|------|-------|------|
| **字号** | 48px | 所有范式统一，老人看得清 |
| **持续时间** | 1000ms | 文献标准：800-1200ms 内不影响节奏（Maddox & Balota 2015）。统一1秒 |
| **正确色** | `#2E7D32`（深绿） | 比 #4CAF50 深一档，白底黑底灰底都能看清 |
| **错误色** | `#C62828`（深红） | 比 #F44336 暗一档，不刺眼，白底黑底灰底都能看清 |
| **居中显示** | `display:flex; align-items:center; justify-content:center; min-height:50vh` | |
| **字体** | `var(--font)`, bold | |

### 反馈文字

| 范式 | 正确时 | 错误时（第1次） | 错误时（第2+次） |
|------|--------|---------------|----------------|
| **Flanker** | ✓ 对了 | 看中间箭头哦 → ←(左) / →(右) | 中间箭头朝左，按左边 |
| **SART** | ✓ 对了 | 看到3不要按哦 (误按时) | 记得要按哦 (漏按时) |
| **N-back** | ✓ 对了 | 没关系，再看仔细 | 没关系，再看仔细 |
| **VSTMB** | ✓ 对了 | 没关系，再看仔细 | 没关系，再看仔细 |

**关键变化**：
- "X" → "✓ 对了" / 柔和提示语
- "错误" → "没关系" / 具体说明
- 红叉 → 深红柔和色 + 无叉号
- 新增正确反馈（之前 Flanker/SART 没有）

### 语音预留

每条反馈文字同时是**语音脚本**，后续接入 TTS 时直接读：
- 正确："对了"（2字，语速170字/分 ≈ 0.7秒）
- 错误："看中间箭头哦"（6字 ≈ 2.1秒）
- 句子都在 ≤10字 以内，符合语音脚本规范

## 四、实现优先级

这个改动涉及每个范式的练习试次逻辑（HTML 模板 + on_finish 判断），改动量大。

建议**等指导语全部重做时一起改**，不要现在单独改——因为：
1. 练习反馈和指导语是连贯体验，分开改会出现风格割裂
2. 标准文档里的递进式反馈（第1/2/3次错误不同提示）需要新的状态追踪逻辑
3. 语音播报功能也要一起设计
