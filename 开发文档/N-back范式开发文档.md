# N-back范式开发文档

---

## 一、概述

视觉情景图片版 N-back 工作记忆测验电池（Digital N-back Battery）是一套短时工作记忆评估工具，采用室内场景图片作为刺激材料。本电池包含四个任务块（Block），覆盖不同的工作记忆负荷水平（0-back / 1-back / 2-back）。

---

## 二、测验内容

### (1) 适用年龄

- **主要适用**：≥60 岁老年人群（HC / SCD / MCI / 早期 AD）
- **扩展适用**：成人对照组（18+），用于建立年龄常模或纵向跟踪

### (2) 任务结构概览

| Block | 负荷级别 | 规则描述 | 作答形式 | 主要测量点 |
|---|---|---|---|---|
| B1 | 0-back | 先学习1张"目标图"，随后判断当前图片与目标图的关系：相同/相似/不同 | 三按钮选择 | 目标保持、分类决策、相似性辨别 |
| B2 | 1-back | 判断当前图片与"上一张"图片的关系：相同/相似/不同 | 三按钮选择 | 工作记忆更新、近距离抑制与辨别 |
| B3 | 1-back（回忆式） | 提示出现时，从3张选项图片中选出"上一张出现过的那张" | 三图选择 | 近期项目提取、错误类型分析 |
| B4 | 2-back | 判断当前图片是否与"前两张"（倒数第二张）完全相同；相同则按键 | 单按钮按键 | 持续监控、速度/准确权衡 |

### (4) 任务描述

#### B1: 0-back（目标图比较）

**规则说明**：

1. 任务开始前学习 1 张"目标图"（固定不变）
2. 随后逐张呈现测试图片
3. 每张图片出现后，被试需判断该图片与目标图的关系：
   - **相同 (Same)**：与目标图完全一致
   - **相似 (Similar)**：与目标图同属一个"场景家族"，但有 1-2 个显著差异（如物体位置改变、开关状态不同）
   - **不同 (Different)**：完全不同的场景

**界面布局**：

- 顶部：固定显示目标图（整个 Block 不变）
- 中央：逐 trial 显示测试图片
- 底部：三个大按钮（相同 / 相似 / 不同）

#### B2: 1-back（和上一张比较）

**规则说明**：

1. 图片逐张呈现
2. 每张图片出现后，被试需判断该图片与"上一张"的关系：相同 / 相似 / 不同
3. 第 1 张为缓冲试次，仅呈现不作答

**界面布局**：

- 中央：场景图片（逐 trial）
- 底部：三个大按钮（相同 / 相似 / 不同）
- 不显示"上一张"内容（被试需要记忆）

#### B3: 1-back 回忆式（固定 Cue 触发，三选一）

**规则说明**：

1. 大多数时间被试只需观看图片（不作答）
2. 当屏幕出现固定的"提示图片（Cue）"时，表示需要作答
3. 此时屏幕下方出现 3 张选项图片，被试需从中选出"上一张出现过的那张"

**界面布局**：

- Stim 阶段：中央呈现场景图（只看不答）
- Cue 触发阶段：中央显示 Cue 图片，下方出现 3 个选项图片（A/B/C）

**选项规则**：

- 正确选项：永远是 Cue 前一张图片（lag=1）
- 诱饵 1：优先取 t-2（近邻干扰）
- 诱饵 2：从刺激池中随机选取（与正确选项和诱饵 1 去重）

#### B4: 2-back（固定按钮 Go/No-Go）

**规则说明**：

1. 图片连续快速呈现
2. 被试需判断当前图片是否与"前两张"（倒数第二张）完全相同
3. 若相同 → 按固定按钮（Go）
4. 若不同 → 不操作（No-Go）
5. 前 2 张为缓冲试次，不计分

**界面布局**：

- 中央：场景图片连续呈现
- 右下角：固定大按钮（"按这里"）

## 三、测验基本参数

### 时序参数汇总

| 参数 | B1 (0-back) | B2 (1-back) | B3 (Lag-1) | B4 (2-back) |
|---|---|---|---|---|
| 刺激呈现时长 | 1000 ms | 1000 ms | Stim: 700 ms / Cue: 200 ms | 800 ms |
| 作答窗口 | 2500 ms | 2500 ms | 3000 ms | ~1000 ms/trial |
| 试次间隔 (ISI) | 250 ms | 250 ms | Stim: 200±40 ms / Probe: 250 ms | 200 ms |
| 点击确认高亮 | 150 ms | 150 ms | 150 ms | 150 ms |
| 超时处理 | 记录 none，进入下一试次 | 同左 | 同左 | 同左 |

### 试次数量

| Block | 练习试次 | 正式试次 | 说明 |
|---|---|---|---|
| B1 | 4 | 20 | 练习有反馈，正式无反馈 |
| B2 | 5（含1张缓冲） | 21（含1张缓冲，20 个计分） | 缓冲试次仅呈现不作答 |
| B3 | Stim 7 张 + Probe 2 次 | Stim 19 张 + Probe 5 次 | 两次 Probe 之间插入 3-4 张 Stim |
| B4 | 6（2 缓冲 + 2 target + 2 foil） | 22（2 缓冲 + 6 target + 14 foil） | Target 比例 30%（6/20 计分试次） |

### 条件配比（正式试次）

| Block | Same | Similar | Different | Target (press) | Foil (none) |
|---|---|---|---|---|---|
| B1 | 6 | 6 | 8 | - | - |
| B2 | 6 | 6 | 8 | - | - |
| B3 | - | - | - | Probe 5 次 | - |
| B4 | - | - | - | 6 | 14 |

### 其他参数

| 参数 | 数值 | 说明 |
|---|---|---|
| 图片分辨率 | ≥1024×768 (4:3) | 保证老年人可见性 |
| 按钮大小 | 大按钮，触摸友好 | 适配触屏/平板 |
| 单块时长上限 | ≤80 秒 | 降低疲劳 |
| 总测验时长 | 约 5-8 分钟 | 含指导语与休息 |
| 过场页最短等待 | 0.8 秒 | 防止误触连击 |

## 四、实验流程

### 总体流程

```
总指导语（1.png）
↓
B1: 指导语 → 练习（有反馈）→ 正式（无反馈）
↓
休息页（2.png）
↓
B2: 指导语 → 练习 → 正式
↓
休息页（2.png）
↓
B3: 指导语 → 练习 → 正式
↓
休息页（2.png）
↓
[条件判断] → 满足条件进入 B4，否则跳过
↓
B4: 指导语 → 练习 → 正式（可选）
↓
结束
```

### B4 进入条件（可配置）

B4（2-back）为高难度任务，默认设置门控条件以降低被试挫败感：

| 条件 | 阈值 | 说明 |
|---|---|---|
| B3 完成时间 | ≤270 秒（4分30秒） | 确保被试能跟上节奏 |
| B2 正确率 | ≥80% | 确保 1-back 基本掌握 |
| B3 正确率 | ≥80% | 确保回忆式任务基本掌握 |

若不满足条件，跳过 B4 并记录 `skip_reason`。

### 单块任务流程（以 B1 为例）

1. **指导语页面**：显示该任务的规则说明图片，最短显示 200 ms，按空格或点击继续
2. **目标图学习**（仅B1）：呈现目标图，被试确认后进入练习
3. **练习阶段**：
   - 4 个练习试次
   - 每次作答后显示反馈（正确/错误）约 200 ms
4. **练习结束提示**：提示即将进入正式阶段
5. **正式阶段**：
   - 20 个正式试次
   - 无反馈
   - 超时未答记录为 none，直接进入下一试次
6. **Block 结束**：进入休息页

## 五、刺激材料

> ⚠ 注意：刺激材料尚未最终确定。请先完成整体程序逻辑的开发，后续我们会提供正式的实验材料。

### 场景图片规范

| 规范项 | 要求 |
|---|---|
| 分辨率 | ≥1024×768（或等比例 4:3） |
| 风格 | 真实照片或高质量 3D 渲染，同一 Block 内风格一致 |
| 场景统一 | 所有图片使用同一**类**场景（如全部为客厅），避免不同房间之间差异过大 |
| 画面要求 | 避免人脸特写、避免大量文字/标识牌、高对比度、主体清晰、整体简洁 |
| 尺寸 | 呈现时等尺寸居中（不用大小作为线索） |

### Similar（相似）图片的定义

| 类型 | 定义 | 说明 |
|---|---|---|
| **Same** | 完全相同（像素一致） | 同一张图片 |
| **Similar** | 同一场景，仅改变 1-2 个显著且明显的特征 | 主要通过颜色变化来区分（如沙发颜色、窗帘颜色等），变化要非常明显 |
| **Different** | 完全不同的图片 | 同一场景类型下的不同布局/角度 |

## 六、序列控制

### 平行版本（List A/B/C）

为支持复测轮换，每个 Block 准备 3 套等价的试次序列（List A/B/C）：

| 版本 | 用途 | 说明 |
|---|---|---|
| List A | 首次测试 | 默认使用 |
| List B | 复测 1 | 更换目标图/序列 |
| List C | 复测 2 | 更换目标图/序列 |

**要求**：

- 各 List 的条件配比、难度、统计特性等价
- 刺激序列采用固定伪随机（对被试随机，对研究者确定）
- 不同 List 使用不同的目标图（B1）或刺激集

### 序列文件结构

序列文件存放在 `lists/` 目录，采用 CSV 格式：

```
lists/
├── B1_ListA.csv
├── B1_ListB.csv
├── B1_ListC.csv
├── B2_ListA.csv
├── B3_ListA.csv
└── B4_ListA.csv
```

| 字段 | 说明 |

## 七、错误判定与反馈

### 错误类型

| Block | 错误类型 | 说明 |
|---|---|---|
| B1/B2 | Same-Similar 混淆 | 将 Similar 误判为 Same，或反之 |
| B1/B2 | Same-Different 混淆 | 将 Different 误判为 Same，或反之 |
| B1/B2 | Similar-Different 混淆 | 将 Similar 误判为 Different，或反之 |
| B1/B2 | 超时 (none) | 在反应窗口内未作答 |
| B3 | 近邻侵入 | 选择了 t-2 或 t-3 的图片 |
| B3 | 随机侵入 | 选择了无关的图片 |
| B3 | 漏答 (miss) | 超时未作答 |
| B4 | 漏报 (Miss) | 应按未按 |
| B4 | 虚报 (False Alarm) | 不应按却按了 |

### 反馈规则

| 阶段 | 反馈方式 |
|---|---|
| 练习阶段 | 作答后显示正确/错误反馈（约 200 ms） |
| 正式阶段 | **无反馈**（减少干扰） |
| B4 按键反馈 | 按键后按钮短暂闪烁（150 ms），不打断节拍 |
| 超时处理 | 不弹窗提示，直接进入下一试次 |

## 九、评分标准与统计指标

### B1/B2（S/S/D 三分类）

| 指标 | 计算方式 | 用途 |
|---|---|---|
| 总正确率 | 正确数 / 总试次数 | 综合表现 |
| 分条件正确率 | 各条件正确数 / 该条件试次数 | 条件差异 |
| 正确 RT 中位数 | 仅计算正确试次的 RT | 加工速度 |
| 漏答率 | 超时试次数 / 总试次数 | 注意持续性 |
| LDI-like 指标 | P(回应=Similar \| Similar) - P(回应=Similar \| Different) | 相似性辨别敏感度 |

### B3（Lag-1 回忆式）

| 指标 | 计算方式 | 用途 |
|---|---|---|
| Cue 正确率 | 正确选择数 / Cue 总数 | 近期记忆提取 |
| 正确 RT 中位数 | 仅计算正确试次的 RT | 提取速度 |
| 近邻侵入比例 | 选择 t-2/t-3 的次数 / 错误总数 | 时间顺序混淆 |
| 随机侵入比例 | 选择无关图片的次数 / 错误总数 | 记忆失败 |
| 漏答 (miss) 次数 | 超时未答次数 | 任务参与度 |

### B4（2-back）

| 指标 | 计算方式 | 用途 |
|---|---|---|
| Hit rate | 命中数 / Target 总数 | 检测敏感性 |
| False Alarm rate | 虚报数 / Foil 总数 | 反应偏向 |
| Miss rate | 漏报数 / Target 总数 | 注意失误 |
| Correct Rejection | 正确拒绝数 / Foil 总数 | 抑制控制 |
| d'（敏感性） | Z(Hit) - Z(FA) | 信号检测敏感性 |
