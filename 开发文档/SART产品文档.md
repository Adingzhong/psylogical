# SART范式编写手册

## SART范式编写手册

## 一、概述

### 1.1 范式简介

SART（Sustained Attention to Response Task，持续注意反应任务）是Robertson等人（1997）开发的经典Go/No-Go任务范式。该任务通过高频Go反应建立"自动按键倾向"，再用低频No-Go刺激诱发抑制控制需求，用于测量持续注意能力。

### 1.2 理论基础

- **核心机制**：被试对频繁出现的非目标刺激（Go）持续按键，形成自动化反应倾向；当低频目标刺激（No-Go）出现时，需要主动抑制这种自动化反应
- **测量目标**：持续注意能力、反应抑制能力、走神（mind-wandering）频率

### 1.3 适用人群

- 中老年人

## 二、实验设计

### 2.1 刺激材料

**(1) 刺激类型**

| 类型 | 刺激内容 | 反应要求 | 出现比例 |
|---|---|---|---|
| Go刺激 | 数字 1,2,4,5,6,7,8,9 | 按键反应 | 88.9% (8/9) |
| No-Go刺激 | 数字3 | 抑制反应（不按键） | 11.1% (1/9) |

**(2) 呈现参数**

- **呈现位置**：屏幕中央
- **背景颜色**：黑色
- **刺激颜色**：白色
- **字体**：44pt Courier New
- **刺激内容**：单个阿拉伯数字（1-9）

**(3) 反应方式**

- **Go trials**：按屏幕上的白色按钮
- **No-Go trials**：不按键（抑制反应）

### 2.2 时间参数

| 参数 | 数值 | 说明 |
|---|---|---|
| 刺激呈现时间 | 1250 ms | 数字在屏幕上显示的时间 |
| 空白屏幕时间 | 1250 ms | 黑色背景空屏，刺激消失后呈现 |
| 单个Trial总时长 | 2500 ms | 刺激呈现+空白屏幕 |
| 反应窗口 | 2500 ms | 从刺激出现到下一刺激出现，被试可在整个周期内反应 |
| 有效RT范围 | 150-2000 ms | 超出此范围的RT将被剔除 |

**反应窗口说明**

- **被试的反应窗口为整个2500ms周期（刺激呈现1250ms + 空白屏幕1250ms）**
- 刺激呈现1250ms后自动消失，进入黑色空白屏幕阶段
- 被试可以在刺激呈现期间或空白屏幕期间做出反应，只要在下一个刺激出现前按键即可
- 如果被试在整个2500ms内未对Go刺激做出反应，则记录为omission error（漏报错误）
- RT计算：从刺激出现时刻到按键时刻的时间差

### 2.3 Probe设计（思维探测）

- **指导语**："请用1-9分评价你刚才对任务的专注程度（1=完全不专注，9=非常专注）"
- **作答方式**：滑动屏幕上的滑轨进行1-9分评分
- **出现**：当所有试次结束后呈现probe

## 三、实验流程

### 3.1 指导语设计

**屏幕1：欢迎与任务背景**

> *（字体要大，背景黑色，文字居中）*
>
> 欢迎参加"眼疾手快"挑战赛！
>
> 待会儿，屏幕中间会一个个地跳出数字从1-9的数字。
>
> 您的任务非常简单：看到这些数字就**按屏幕下方的白色按钮**。
>
> 但是，这里面藏着一个"捣乱的数字"，您要小心它！
>
> *（请按白色按钮继续）*

**屏幕2：核心规则**

> *（数字"3"可以用醒目的红色或加粗显示，旁边可以画一个禁止的手势图标）*
>
> 这个捣乱的数字是 **3** 。
>
> 请记住口诀：
>
> > 看到数字 3 ：千万别按！忍住！
> >
> > 看到其他数字 ：请快速按键！
>
> *（请按白色按钮继续）*

**屏幕3：练习阶段**

> *（左边是数字7+按键手势，右边是数字3+停止手势）*
>
> **接下来我们先来热身一下。**
>
> > 请记住：除了捣乱数字"3"以外，其他所有的数字都要按键！
> >
> > 请您在**看清数字**的前提下，**越快按键越好**。
> >
> > 接下来的练习中，如果您按错了，屏幕会告诉您。
> >
> > 如果**不小心按错了也没关系**，继续盯着下一个数字就好。
> >
> > 准备好了吗？请把手指放在白色按钮上。
>
> *（请按白色按钮继续）*

**屏幕3.1：练习失败，再次练习**

> **刚刚出现了一些小错误哦！**
>
> > 请记住：除了捣乱数字"3"以外，其他所有的数字都要按键！
> >
> > 请您在**看清数字**的前提下，**越快按键越好**。
> >
> > 让我们再练习一次吧！
>
> *（请按白色按钮开始游戏）*

**屏幕4：练习后/正式开始前**

> **热身结束，您做得很好！**
>
> > 接下来就**正式**开始游戏！
>
> 注意:
>
> > a. 这次时间会比较长（大约3分钟）。
> >
> > b. 就算按错了，屏幕也**不会**再提示您，请坚持做下去。
>
> **深呼吸，保持专注。看到 3 忍住不按，看到其他数字快快按！**
>
> *（请按白色按钮开始游戏）*

### 3.2 练习阶段

- 9个tials，包含7个 go 和2个 no-go
- go：在1-9（除了3）的数字中随机选择7个数字
- no-go：固定在第4个和第7个 trial 中呈现
- 练习阶段准确率需达到70%（go至少对6个，no-go至少对1个），否则再次进入练习阶段
- 练习阶段最多呈现2次

### 3.3 正式阶段

| 参数 | 数值 | 说明 |
|---|---|---|
| Trial总数 | 36 | 9个数字 × 4次 = 36 |
| No-Go trials | 4个 (11.1%) | 数字3出现4次 |
| Go trials | 32个 (88.9%) | 非3数字各出现4次 |
| Probe次数 | 1次 | 试次结束后 |
| 预计时长 | 约2-3分钟 | 总试次时长：36 trials × 2.5s = 90s |

## 四、数据收集与输出

### 4.1 程序记录数据（原始数据）

以下是程序在运行过程中需要记录的所有数据字段，包括Trial数据和Probe数据。

| 分类 | 字段名 | 说明 | 取值说明 |
|---|---|---|---|
| 基本信息 | subject_id | 被试唯一编号 | |
| 基本信息 | block_type | 阶段类型 | "practice1"/"practice2"/"formal" |
| 基本信息 | trial_index | 当前阶段内试次序号 | |
| 刺激信息 | digit | 当前呈现的数字 | |
| 刺激信息 | trial_type | 试次类型 | "go"/"nogo" |
| 时间戳 | stim_onset_ts | 刺激出现时间戳(ms) | |
| 时间戳 | stim_offset_ts | 刺激消失时间戳(ms) | |
| 反应数据 | response_made | 是否有按键反应 | 无按键为0，有按键为1 |
| 反应数据 | reaction_time_ms | 反应时(ms)，从刺激出现到按键 | |
| 正确性判断 | accuracy | 是否正确 | |
| 正确性判断 | error_type | 错误类型（见下方说明） | null/"commission"/"omission" |
| Probe | probe_onset_ts | Probe出现时间戳(ms) | |
| Probe | probe_response_ts | Probe作答时间戳(ms) | |
| Probe | probe_rt_ms | Probe反应时(ms) | |
| Probe | attention_rating | 专注度评分(1-9) | |

**error_type 字段说明**

| 取值 | 含义 | 说明 |
|---|---|---|
| null | 无错误 | 反应正确：Go trial按键 或 No-Go trial未按键 |
| "commission" | 虚报错误 | No-Go trial（数字3）时错误地按了键 |
| "omission" | 漏报错误 | Go trial（非3数字）时未按键 |

**判断逻辑**：

- **Go trial（非3数字）**：
  - 按键 → accuracy=1, error_type=null
  - 未按键 → accuracy=0, error_type="omission"
- **No-Go trial（数字3）**：
  - 未按键 → accuracy=1, error_type=null
  - 按键 → accuracy=0, error_type="commission"

## 五、数据清理规则

### 5.1 RT清理

1. **绝对阈值剔除**：剔除 RT < 150 ms 或 RT > 2000 ms 的trials
2. **相对阈值剔除**：在上述基础上，剔除超出被试自身均值 ± 3SD 的RT
3. **记录剔除信息**：保留被剔除trial的标记，用于后续分析

### 5.2 被试排除标准

| 排除条件 | 阈值 | 说明 |
|---|---|---|
| Go准确率过低 | | 可能未理解任务 |
| No-Go准确率过低 | | 可能未理解任务 |
| 有效trial过少 | | 数据不足（正式阶段共36trials） |
| RT均值异常 | | 反应策略异常 |

## 六、核心分析指标说明

### 6.1 Commission Errors（虚报错误/False Alarms）

- **定义**：在No-Go刺激（数字3）出现时错误地按键
- **意义**：反映反应抑制能力和持续注意水平
- **临床价值**：MCI和AD患者通常表现出更高的commission error率

### 6.2 RT CoV（反应时变异系数）

- **计算**：CoV = RT标准差 / RT均值
- **意义**：反映反应时的稳定性，高CoV表示注意力波动大
- **临床价值**：AD早期患者表现出显著更高的CoV

### 6.3 Pre-error Speeding（错误前加速）

- **计算**：正确No-Go前4个trials的RT均值 - 错误No-Go前4个trials的RT均值
- **意义**：正值表示错误前存在反应加速，反映"无意识"的自动化反应
- **临床价值**：所有年龄组都表现出pre-error speeding

### 6.4 Post-error Slowing（错误后减速）

- **计算**：错误后第1个trial的RT - 正确No-Go后第1个trial的RT
- **意义**：正值表示错误后存在反应减速，反映错误监控和任务重新投入
- **临床价值**：健康老年人表现出更大的post-error slowing，但AD患者可能减弱

### 6.5 Skill Index（技能指数）

- **计算**：(No-Go准确率 / Go RT均值) × 1000
- **意义**：综合考虑准确性和速度的指标，控制速度-准确性权衡
- **临床价值**：随年龄和认知衰退系统性下降

## 七、参数汇总表

| 参数类别 | 具体内容 |
|---|---|
| 测验范式 | 数字 Go/No-Go SART |
| 刺激呈现 | 白色刺激、黑色背景 |
| 刺激材料 | 数字1-9 |
| 字体 | 44pt Courier New |
| 条件类型 | Go（非3）/ No-Go（3） |

| 练习trials | 9 trials |

| 预计总时长 | 约2-3分钟（含练习） |
