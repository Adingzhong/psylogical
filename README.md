# 老年范式综合2

这是认知老化/认知测评平台相关材料的综合仓库，包含当前 Web 平台、原始开发文档、旧版范式程序、试测反馈、文献证据和交接说明。

如果你是第一次打开这个仓库，建议先看：

1. `docs/handoff/README.md`
2. `docs/handoff/认知测评平台_协作者审核说明.md`
3. 只在需要机器辅助深挖时，再看 `docs/handoff/认知测评平台_Codex交接说明.md`

## 审核任务

后续负责人主要任务是读当前版本和原始设计，对照证据判断修改是否合理。这个仓库当前不是要求大家直接写新功能。

请重点确认：

- 当前 Web 实现是否仍符合原始范式逻辑；
- 适老化修改是否有试测反馈或文献依据；
- 参数变化是否会影响数据质量；
- 哪些文件不适合公开上传或需要匿名化。
