# paradigms

这个目录是当前 Web 认知测评平台的范式代码目录。

每个重点范式通常包含：

- 一个 `.html` 页面；
- 一个 `.js` 实验流程文件；
- 可选的 `img/`、`layouts/`、`lists/` 等材料或配置目录。

重点子目录：

| 子目录 | 范式 |
|---|---|
| `flanker/` | Flanker / 箭头判断 |
| `sart/` | SART / 数字注意 |
| `nback/` | 图片记忆 / N-back |
| `vstmb/` | VSTMB / 视觉短时记忆 |
| `tmt/` | 连线测试 / TMT |
| `clock/` | 画钟测试 |
| `visuospatial/` | 空间导航 |
| `rmet/` | 看眼读心 / RMET |
| `speech/` | 语音测评 |
| `precheck/` | 设备预检 |
| `interpersonal/` | 人际距离 |
| `eyetracking/` | 眼动/自然注视相关任务 |

交接审核时，先读 `docs/handoff/认知测评平台_协作者审核说明.md`，再进入对应子目录。
