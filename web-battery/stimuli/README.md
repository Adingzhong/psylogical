# stimuli

这个目录保存当前 Web 平台运行时使用的刺激材料。

重点子目录：

| 子目录 | 用途 |
|---|---|
| `flanker/` | Flanker 箭头图片 |
| `nback/` | N-back 图片记忆材料 |
| `nback-instructions/` | N-back 指导语图片 |
| `rmet/` | RMET 眼部图片 |
| `speech/` | 语音测评图片/朗读材料 |
| `tmt-fruits/` | TMT 水果节点图片 |
| `vstmb/` | VSTMB 图形/颜色材料 |
| `interpersonal/` | 人际距离材料 |
| `eyetracking/` | 眼动/自然注视材料 |

审核材料难度或图片是否符合原始设计时，优先看这里。
