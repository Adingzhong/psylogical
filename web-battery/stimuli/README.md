# stimuli

这个目录保存当前 Web 平台运行时使用或审核需要查看的轻量刺激材料。

协作版优先保留 WebP/JPG 版本，用于查看当前任务材料和辅助审核。原始 PNG/JPG 大图副本、旧版素材工程和过程图片没有整包上传；如果需要做像素级材料复核，再按范式单独补原始素材包。

重点子目录：

| 子目录 | 用途 |
|---|---|
| `flanker/` | Flanker 箭头图片 |
| `nback/` | N-back 图片记忆材料 |
| `nback-instructions/` | N-back 指导语图片 |
| `rmet/` | RMET 眼部图片 |
| `speech/` | 语音测评图片/朗读材料 |
| `tmt-fruits/` | TMT 水果节点图片 |
| `vstmb/` | VSTMB 图形/颜色材料 |
| `interpersonal/` | 人际距离材料 |
| `eyetracking/` | 眼动/自然注视材料 |

审核材料难度或图片是否符合原始设计时，优先看这里。
