# audio

这个目录保存当前 Web 平台使用的语音指导音频。

重点子目录：

| 子目录 | 用途 |
|---|---|
| `flanker/` | Flanker 指导语 |
| `sart/` | SART 指导语 |
| `nback/` | N-back 指导语 |
| `vstmb/` | VSTMB 指导语 |
| `tmt/` | TMT 指导语 |
| `clock/` | 画钟指导语 |
| `visuospatial/` | 空间导航指导语 |
| `rmet/` | RMET 指导语 |
| `speech/` | 语音测评指导语 |
| `precheck/` | 设备预检指导语 |

部分 `_backup_old_*` 目录是旧音频备份，公开上传前需要人工确认是否保留。
